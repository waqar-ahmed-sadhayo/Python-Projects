# 😂 Funny Fake News Generator

A fun and interactive **Streamlit web application** that generates hilarious, AI‑powered fake news headlines. Just pick a category or add your own topic — and the app delivers absurd, creative, and entertaining news headlines instantly!

---

## 🚀 Live Demo

Click below to try the app:

👉 **[https://funny-fake-news-generator.streamlit.app](https://funny-fake-news-generator.streamlit.app)**

---

## 📌 Features

* 📰 Generates funny fake news headlines
* 🎯 Choose from predefined categories
* ✍️ Add your own custom topic
* 🔄 Generate unlimited random headlines
* 💾 Download headlines as `.txt`
* 🎨 Clean UI made with Streamlit

## 🛠️ Installation (Run Locally)

1. Clone the repository:

```bash
git clone https://github.com/your-username/funny-fake-news-generator
```

2. Navigate to the project folder:

```bash
cd funny-fake-news-generator
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Streamlit app:

```bash
streamlit run app.py
```

## 🧠 How It Works

* The app uses Python lists and random selection to generate creative headlines.
